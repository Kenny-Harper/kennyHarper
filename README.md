# KennyHarper – Portfolio Projects

Welcome to my portfolio repository for the IT Career Switch program.  
This repo contains a collection of projects built to demonstrate my growing skillset in full-stack web development.

Across these projects, I work with:
- **PHP** for backend logic  
- **JavaScript** for dynamic UI behaviour  
- **AJAX** for asynchronous data handling  
- **REST APIs** for external data integration  
- **Frontend libraries** for UI enhancements  

Each project highlights a different part of the development process, from problem-solving and data manipulation to user experience and interface design.

---

## 📍 Project 1: Gazetteer

A fully interactive, web-based **Gazetteer application** that provides **real-time information** about countries around the world. 

The system brings together multiple data sources to display **weather**, **news**, **cities**, **airports**, **Wikipedia summaries**, **demographics**, and **currency exchange rates**.

Designed as a modern **geographic information tool**, it allows users to explore countries visually and retrieve **live data** through a custom **PHP backend** and several **external APIs**.

---

## 📌 Project 2: Company Directory

A responsive, web-based **Company Directory application** that allows users to manage **Personnel**, **Departments**, and **Locations** within a company.

The system supports full CRUD functionality using a clean tab-based interface with **Bootstrap modals**, **plus search** and **filtering** to quickly find employees by **department** or **location**.

Built with a **PHP + MySQL** backend and a dynamic **JavaScript (jQuery/AJAX) frontend**, ensuring data stays up to date while protecting database integrity by preventing deletion of records with dependencies.
