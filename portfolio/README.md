# Portfolio Website

This folder contains my personal portfolio website, built to showcase my projects, skills, and experience as part of my journey into full-stack web development.

🌐 **Live site:**  
https://kennyharper.co.uk/portfolio/

---

## Overview
This portfolio highlights a range of projects demonstrating my ability to design, build, and deploy responsive, data-driven web applications.

The site brings together frontend presentation and backend functionality, with a focus on clean structure, usability, and real-world development practices.

---

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP (PHPMailer)

---

## Features
- Responsive layout optimised for desktop and mobile
- Project case studies with supporting screenshots
- Contact form powered by a secure PHP mail handler
- Reusable components and organised asset structure
